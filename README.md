# 🦇 Buffyverse TCG

**An unofficial, non-commercial Buffyverse Trading Card Game for Windows.**

Welcome to Buffyverse TCG, a fan-made trading card game inspired by the world of *Buffy the Vampire Slayer*.

The game is currently in development, with more card artwork, improvements and additional content planned for future updates.

## 🎮 Download

**Current version:** v1.3.0 (Pre-release)

**Platform:** Windows

[Download Buffyverse TCG v1.3.0](https://github.com/Whitelighter26/BuffyverseTCG/releases/tag/v1.3.0)

## 📦 Installation

1. Download `Buffyverse-TCG-v1.3.0-Windows.zip` from the release page.
2. Extract the ZIP file completely.
3. Open the extracted folder.
4. Double-click `Buffyverse TCG.exe` to start playing.

No separate installation is required.

## 🎮 Controls & Settings

- **F11:** Toggle fullscreen mode.
- **M:** Toggle sound on/off.
- **Language:** Change the language under Settings → Language.
- **Default language:** English.

## 💾 Save Data & Updates

Your game progress is stored separately in:

`%APPDATA%\Buffyverse TCG`

To update the game, replace the previous game folder with the files from the latest release.

Your saved progress will be preserved.
